Understanding the Language Model API

A comprehensive guide to integrating AI capabilities in your applications

Overview

The Language Model API provides a powerful way to integrate AI capabilities into your applications. This guide covers everything you need to know about making API calls, formatting requests, and handling responses.

Basic Usage

Simple API Call


async function getAIResponse() {
  try {
    const response = await fetch('/api/ai_completion', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Accept': 'application/json',
      },
      body: JSON.stringify({
        prompt: 'Generate a creative story about a space explorer.',
        data: 'Additional context or history can go here'
      })
    });
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Error:', error);
    return null;
  }
}

Advanced Features

Structured Responses

Define TypeScript interfaces to get structured responses:


interface StoryResponse {
  title: string;
  content: string;
  tags: string[];
}

async function getStructuredStory() {
  const response = await fetch('/api/ai_completion', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json',
    },
    body: JSON.stringify({
      prompt: `Generate a short story with tags.
      
      interface Response {
        title: string;
        content: string;
        tags: string[];
      }
      
      {
        "title": "The Red Door",
        "content": "A mysterious door appeared...",
        "tags": ["mystery", "supernatural", "short"]
      }
      `,
      data: ''
    })
  });
  return await response.json();
}

Chat Conversations

Handle back-and-forth conversations:


async function getChatResponse(messages) {
  const response = await fetch('/api/ai_completion', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json',
    },
    body: JSON.stringify({
      prompt: `Respond as a helpful assistant.
      
      interface Response {
        message: string;
        sentiment: "positive" | "neutral" | "negative";
      }
      
      {
        "message": "I'd be happy to help you with that!",
        "sentiment": "positive"
      }
      `,
      data: messages
    })
  });
  return await response.json();
}

Pure HTML Implementation

Here's the simplest possible way to use the LLM API with just HTML - no JavaScript required:

Complete HTML Example


<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Simple LLM Demo</title>
  <style>
    form { max-width: 500px; margin: 20px auto; }
    textarea { width: 100%; min-height: 100px; margin: 10px 0; }
    iframe { width: 100%; min-height: 200px; border: 1px solid #ccc; }
  </style>
</head>
<body>
  <form action="/api/ai_completion" method="POST" target="responseFrame">
    <div>
      <label for="prompt">Enter your prompt:</label>
      <textarea name="prompt" id="prompt" required>Generate a creative story about...</textarea>
    </div>
    
    <div>
      <label for="data">Context (optional):</label>
      <textarea name="data" id="data"></textarea>
    </div>
    
    <button type="submit">Get AI Response</button>
  </form>

  <iframe name="responseFrame" title="AI Response"></iframe>
</body>
</html>

How it works:

  1. The form's action points to the LLM API endpoint
  2. The method="POST" ensures proper API submission
  3. The form targets an iframe named "responseFrame" using target="responseFrame"
  4. When submitted, the API response automatically displays in the iframe
  5. The response includes proper JSON formatting for readability

Note: This is the simplest possible implementation. For production use, consider adding error handling and response formatting with JavaScript.
