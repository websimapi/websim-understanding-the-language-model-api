Simple LLM API Example

This example shows how to use the LLM API with pure HTML - no JavaScript required!

Try it out:



How it works:

Here's the HTML code that makes this work:

<form action="/api/ai_completion" method="POST" target="responseFrame">
  <div>
    <label for="prompt">Prompt:</label><br>
    <textarea name="prompt" required>Generate a creative story about space exploration.

{
  "story": "A mysterious signal echoes through the void...",
  "title": "Deep Space Mystery",
  "wordCount": 150
}</textarea>
  </div>
  
  <div>
    <label for="data">Additional Context (optional):</label><br>
    <textarea name="data"></textarea>
  </div>
  
  <button type="submit">Generate Story</button>
</form>

<iframe name="responseFrame" title="API Response"></iframe>

Key Points:

  • The form uses standard HTML POST method to send data to the API endpoint
  • Response is displayed in an iframe (target="responseFrame")
  • No JavaScript or external dependencies needed
  • Example response format is included in the prompt
